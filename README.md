# Эльстома — сайт стоматологического центра

Статический сайт (HTML + CSS + JS), без сборки и серверной части.

- `index.html` — разметка
- `styles.css` — стили
- `main.js` — анимации, схема зубов, карта, форма записи

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в его корень `index.html`, `styles.css`, `main.js`, `.nojekyll`.
2. Откройте **Settings → Pages**.
3. В **Source** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Где менять данные

В начале `main.js`, объект `CLINIC`: координаты, номер WhatsApp, график работы.
Телефон и адрес — в `index.html` (поиск по `+996773907878` и `Кок-Жар`).

Заявка с формы открывается в WhatsApp с готовым текстом — сервер не нужен.

## Фото врачей

- `img/doctors/1.jpg … 5.jpg` — облегчённые фото для сайта (сайт показывает 1–4).
- `photos/1.png … 5.png` — исходники в полном качестве (на сайте не используются).

Чтобы поставить 5-е фото вместо 4-го: в `index.html` найдите `img/doctors/4.jpg`
и замените на `img/doctors/5.jpg`. Не забудьте поменять ФИО, должность и опыт в той же карточке.
